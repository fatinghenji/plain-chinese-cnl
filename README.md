# plain-chinese-cnl

面向普通读者的中文平实写作规则：按 ISO 24495-1:2023《Plain language — Part 1》的四原则组织，附带中文特化细则、改写示例与交付前检查清单。

## 用途

中文公文、通知、说明书、产品文档常见的毛病集中在几处：结论埋在最后，长句一逗到底，术语与缩写不解释，中英夹杂，指代含糊（「相关单位」「该部分」）。这份规则把这些毛病逐条列出改法，并给出改写前后的对照。判断标准是读者能不能找到、读懂、照着做，把语言写简单只是手段之一。

## 内容

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 规则主体：四原则细则、中文特化条目、检查清单、常见误区；每条标注 ISO 24495-1 的条款号 |
| `references/before-after-zh.md` | 六组改写前后对照，各标注动用的原则 |

`SKILL.md` 顶部的 YAML frontmatter 是 Hermes Agent 的技能格式，可以整份复制进技能目录使用；其他工具或人工阅读时忽略 frontmatter 即可。

## 四原则

| 原则 | 一句话 |
|---|---|
| 相关 | 读者得到他们需要的 |
| 好找 | 读者能快速找到要的 |
| 好懂 | 读者能看懂找到的 |
| 能用 | 读者能照着做 |

四条相互依赖，写作前定方向、写作中管结构与语言、写完靠最后一条验证。

## 适用边界

适用于写给人读的说明类文本：面向公众的通知与公告、用户文档与操作指南、科普文章、政策与条款说明、客服回复、培训材料、知情同意类文书。

术语密度正当的场合（同行评议论文、专业领域内部的讨论记录、法规原文引用）不适用，照搬本规则会把效率削掉。

## 溯源

规则按 ISO 24495-1:2023《Plain language — Part 1》整理，保留条款号以便对照。ISO 标准全文受版权保护，向 ISO 或各国成员体购买；本仓库只复述规则要点并引用条款编号，不收录原文。

中文手法层与示例素材部分改写自 [danyuchn/iso-24495-skill](https://github.com/danyuchn/iso-24495-skill)（MIT），已简体化并按大陆用法调整用词。

文中数字门槛（句约 40 字、一段五句、连用三个「的」）为自拟警戒线，不是标准条文。
